```
1. Login as patient
2. Click "AI Symptom Checker"
3. Enter: "I have chest pain and breathless"
4. Click "Analyze Symptoms"
5. See AI recommendation for Cardiologist
6. Click "Book Appointment"
```

### 2. Voice Navigation:
```
1. Click microphone button (bottom-right)
2. Select language (English/Hindi/Tamil)
3. Click "Start Voice Command"
4. Say: "Book appointment"
5. App navigates to booking page
6. Try other commands: "Find doctors", "Help"
```

### 3. Emergency SOS:
```
1. Click red button (bottom-left)
2. See emergency modal
3. Location automatically detected
4. Click "CONFIRM EMERGENCY"
5. See confirmation with emergency numbers
```

### 4. PWA:
```
1. Open app on mobile browser
2. See "Add to Home Screen" prompt
3. Install the app
4. Works offline (try airplane mode)
5. Fast loading
```

### 5. Medicine Reminders:
```
1. Login as patient
2. Click "Medicine Reminders"
3. Click "Add Reminder"
4. Fill form:
   - Medicine: Aspirin
   - Dosage: 1 tablet
   - Times: 09:00 AM, 09:00 PM
   - Duration: 7 days
5. Click "Create Reminder"
6. Allow notifications
7. Get alerts at scheduled times
```
